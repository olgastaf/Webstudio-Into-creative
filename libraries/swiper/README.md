# Swiper

## Описание

**Swiper** — JavaScript-библиотека для создания слайдеров и каруселей с поддержкой сенсорного управления.

Используется для реализации:
- каруселей товаров;
- слайдеров изображений и баннеров;
- табов со слайдерами;
- слайдеров с независимым управлением;
- адаптивных каруселей с разным количеством элементов на разных разрешениях экрана.

Официальный сайт: https://swiperjs.com/

Репозиторий проекта: https://github.com/nolimits4web/swiper

## Назначение в базе знаний

Библиотека хранится в общем каталоге `libraries/` для повторного использования в разных проектах веб-студии.

В частности, Swiper может использоваться при разработке и кастомизации шаблонов компонентов 1С-Битрикс.

## Структура файлов

В каталоге хранится локальная копия библиотеки Swiper.

Перед подключением необходимо проверить структуру файлов и определить расположение:
- CSS-файла библиотеки;
- JavaScript-файла библиотеки;
- дополнительных модулей, если они используются.

Для подключения на сайте рекомендуется использовать готовые файлы сборки из каталога `dist`, если они присутствуют в скачанной версии.

## Подключение

Пути к файлам зависят от расположения библиотеки в конкретном проекте.

Пример подключения:

```html
<link rel="stylesheet" href="/путь-к-swiper/swiper-bundle.min.css">

<script src="/путь-к-swiper/swiper-bundle.min.js"></script>
```

Перед использованием необходимо заменить пути на фактические пути к файлам библиотеки на сайте.

## Примечания для разработчиков

- Не изменять файлы библиотеки для решения задач конкретного проекта без необходимости.
- Настройки слайдеров хранить в коде соответствующего проекта.
- Для разных каруселей использовать отдельные экземпляры Swiper, чтобы управление одной каруселью не влияло на остальные.
- Если слайдеры находятся во вкладках или загружаются через AJAX, предусмотреть их инициализацию после отображения вкладки или загрузки содержимого.
- При повторной инициализации проверять, не был ли экземпляр Swiper уже создан.
