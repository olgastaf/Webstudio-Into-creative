# Регистрация и авторизация частных лиц и организаций / ИП

Решение разрабатывается для сайта ddv-e.ru.
Некоторые сценарии интерфейса взяты за ориентир с ekf.market.

Предусмотрена регистрация частных лиц и представителей юридических лиц / ИП с разными наборами полей и назначением соответствующих групп пользователей.

**Статус: в разработке.**

## Инструкция по установке и настройке

### 1. Создание пользовательских полей

Создайте следующие пользовательские поля для пользователей:

| Код поля | Назначение | Тип |
|---|---|---|
| UF_CLIENT_TYPE | Тип клиента: частное лицо или организация / ИП | Список, одиночный выбор |
| UF_INN | ИНН | Строка |
| UF_KPP | КПП | Строка |
| UF_BUSINESS_ADDRESS | Адрес организации / ИП | Строка |

Все поля должны быть одиночными, без множественного выбора.

Для поля UF_CLIENT_TYPE создайте два значения:

| XML_ID | Значение |
|---|---|
| individual | Я частное лицо |
| business | Я являюсь представителем юридического лица или индивидуального предпринимателя |

Тип клиента обязателен для этой формы регистрации. Его выбор проверяется на сервере.

Поля UF_INN, UF_KPP и UF_BUSINESS_ADDRESS не отмечайте обязательными в настройках пользовательских полей. Их обязательность проверяется на сервере в зависимости от выбранного типа клиента. Для ИП КПП не требуется.

Для названия организации / ИП используется стандартное поле пользователя WORK_COMPANY. Создавать отдельное пользовательское поле для названия не нужно.
### 2. Настройка групп пользователей

Используется существующая группа «Зарегистрированные пользователи».
В настройках Главного модуля проверьте, что она включена в список групп, в которые добавляются новые пользователи при регистрации.

Создайте дополнительную группу «Юридические лица и ИП».
Не включайте для неё автоматическое добавление всех новых пользователей.

После регистрации:
- частное лицо получает стандартные группы новых пользователей;
- юридическое лицо / ИП получает стандартные группы и дополнительно группу «Юридические лица и ИП».

На сайте ddv-e.ru ID группы «Юридические лица и ИП» — 8.
На другом сайте ID может отличаться: его необходимо указать в настройках обработчика.
