# Шаблон компонента bitrix:form с кастомизированными полями
Приводится шаблон компонента bitrix:form
Вместо табличной верски исползуются верстка 
<div>
<input>
<lable>
## Что входит в комплект
Код для вывода компонента на странице
Папка шаблона write-to-us
## Особенности
- В неактивном состоянии <label> выводится поверх <input> и выглядит как placeholder в <input>. При клике на нужное поле <label> ументьшается и уходет вверх, на верхнюю границу input, оставляя место для заполнения.
- В шаблоне прописывается различный способ вывода в зависимости от типа полей:
    - text (строка)
    - checkbox (чекбокс)
    - textarea
## Как использовать
1. Создаем Веб-форму в административной части Битрикса в разделе Сервисы/Веб-формы/Настройка форм
1.1. Если необходимы более точные настройки, то в разделе Настройки/Настройки продукта/Настройки модулей/Веб-формы на вкладке Настройки снимаем галочку у пункта "Использовать упрощенный режим редактирования форм".
1.2. Добавляем необходимые поля вопросов
2. Код для вывода компонента вставляем в код страницы в нужное место. При необходимости меняем натройки компонента. В качестве шаблона подключаем write-to-us
3. Шаблон компонента сохраняем в /bitrix/timplate/--название шаблона--/components/bitrix/form/
4. При необходимости меняем стили в файле /bitrix/templates/--название шаблона--/components/bitrix/form/write_to_us/bitrix/form.result.new/.default/style.css

## Особенности реализации
Форма открывается через `$arResult["FORM_HEADER"]`.
Не следует дополнительно добавлять тег `<form>` вручную: `FORM_HEADER`
уже содержит открывающий тег формы. При ручном добавлении получается
невалидная вложенная конструкция `<form>` внутри `<form>`.
В DevTools эта ошибка может быть незаметна, поскольку браузер исправляет
невалидную структуру DOM. Для проверки исходной разметки страницы
используйте «Просмотр исходного кода страницы» (`Ctrl+U`).
