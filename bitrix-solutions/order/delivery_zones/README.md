#Задача
Нужно на яндекс-карте нарисовать зоны и доставки передать это в битрикс таким образом, чтобы выполнялся следующий сценарий:
•	- покупатель вносит свой адрес
•	- на яндекс-карте определяется зона, в которую этот адрес попадает
•	- номер зоны передается в битрикс
•	- битрикс считает стоимость доставки в соответсвии с номером зоны и заложенными в битриксе тарифами на доставку в данную зону.

##Что сделано.
###Создан и заполнен HL-блок зон доставки. 
В блоке есть следующие поля:
Название зоны	UF_NAME	Строка
Номер зоны	UF_ZONE_NUMBER	Целое число
Активна	UF_ACTIVE	Да/Нет
Сортировка	UF_SORT	Целое число
Полигон зоны	UF_GEOJSON	Строка
Центр зоны	UF_CENTER	Строка
Максимальная широта	UF_MAX_LAT	Число
Минимальная широта	UF_MIN_LAT	Число
Максимальная долгота	UF_MAX_LON	Число
Минимальная долгота	UF_MIN_LON	Число
Базовая стоимость	UF_PRICE	Число
Бесплатно от	UF_FREE_FROM	Число
Минимальная сумма заказа	UF_MIN_ORDER_PRICE	Число
Стоимость за кг	UF_UF_PRICE_PER_KG	Число
Срок доставки	UF_DELIVERY_PERIOD	Строка
Приоритет	UF_PRIORITY	Целое число

Сделано три записи:
- Центральная
- Ближняя
- Дальняя
