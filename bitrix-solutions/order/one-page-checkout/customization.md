# Адаптация шаблона

## Где изменено поведение

Основные изменения находятся в `../.default/order_ajax.js`:

| Метод или участок | Изменение |
| --- | --- |
| `editSection` | Переменная `active` установлена в `true`, разделы строятся открытыми |
| `locationsCompletion` | Удалены вызовы, заменявшие поля региона и покупателя свернутым содержимым |
| `fixLocationsStyle` | Стили местоположений применяются к видимому разделу |
| `changeVisibleContent` | Содержимое доступных разделов открывается, кнопка оформления доступна |
| `showActualBlock` | Вызывает `changeVisibleContent`, без последовательного прохождения шагов |
| `getBlockFooter` | Не создаёт навигацию между шагами |
| `showByClick` | Не переключает состояние разделов |
| Переопределения `fade` и `show` в конце файла | Не переносят поля в скрытые контейнеры |
| `getDeliveryLocationInput` | Удалён вывод стандартной подсказки выбора города |

Переопределения в конце файла являются частью решения: при переносе изменений сохраните их вместе с остальными правками.

В конце `style.css` добавлены правила для скрытия ссылок редактирования, навигации, номеров шагов, а также удаления рамок разделов. Заголовки разделов остаются.

## Восстановление подсказки выбора города

В текущей версии подсказка удалена из исходного проекта. Если покупатель выбирает местоположение вручную, её можно вернуть.

В методе `getDeliveryLocationInput: function(node)` добавьте перед закрывающей `},` метода:

```javascript
if (location && location[0])
{
    node.appendChild(
        BX.create('DIV', {
            props: {className: 'bx-soa-reference'},
            html: this.params.MESS_REGION_REFERENCE
        })
    );
}
```

Текст задаётся параметром `MESS_REGION_REFERENCE`; стандартный текст берётся из языковых сообщений шаблона.

## Оформление

Изменяйте визуальные правила в `style.css`. При изменении разметки в `template.php` сохраняйте ID контейнеров `bx-soa-*`, имена полей и атрибуты, которые использует JavaScript компонента.

Скрытие свойства стилями не отменяет его обязательность и серверную проверку. Для другого проекта настройте свойства заказа и их привязки отдельно.

В `template.php` подключается `script.js`. Если будете редактировать его, учитывайте, что `script.min.js` и `script.map.js` — отдельные файлы: они не обновляются автоматически вслед за исходником. То же относится к вариантам скриптов карт.

## Совмещение с доставкой по зонам

Устанавливайте [решение доставки по зонам](../../delivery_zones/) по его собственной инструкции.

Доработки, зависящие от конкретных ID свойств и служб доставки, остаются в том решении. Не переносите в универсальный шаблон ID из исходного проекта.

После подключения дополнительных обработчиков повторно проверьте смену типа покупателя, профиля, доставки, пересчёт и сохранение заказа.
