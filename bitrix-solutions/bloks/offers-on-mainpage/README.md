# Товарные карусели с вкладками на главной странице (1С-Битрикс)

Готовое решение для вывода нескольких независимых товарных блоков («Хиты продаж», «Новинки», «Лучшие предложения» и др.) в произвольных местах страницы. Внутри каждого блока товары сгруппированы по вкладкам и отображаются в карусели Swiper.

**Текущая версия:** рабочая реализация для одного сайта. Настройки блоков и вкладок задаются **вручную** в `config.php`. Автоматическое чтение значений свойств и настройка многосайтовости пока не реализованы.

## Возможности

- Отдельные товарные блоки с произвольным размещением на странице.
- Фильтрация товаров по свойству списка `OFFERS` («Наши предложения»).
- Вкладки по свойству списка `USAGE` («Применение»), первая вкладка — «Все товары».
- Автоматическое скрытие блока, если в нём нет активных товаров, и вкладок без товаров в данном блоке.
- AJAX-переключение вкладок без перезагрузки страницы.
- Независимые карусели Swiper с адаптивным количеством карточек и собственными стрелками.

## Структура репозитория

```text
bitrix-solutions/bloks/offers-on-mainpage/
├── README.md
├── index.php                     # пример страницы с несколькими блоками
├── ajax/
│   └── hit-carousel.php          # AJAX-обработчик вкладок
└── local/
    └── include/
        ├── config.php            # ID инфоблока, свойства, блоки и вкладки
        ├── section.php           # вывод одного товарного блока
        └── offers-carousel.js    # Swiper и AJAX-переключение
```

Swiper и шаблон компонента `slider` должны быть доступны на целевом сайте; их подключение и стили зависят от используемого шаблона сайта.

## Требования

- 1С-Битрикс с модулем `iblock` и инфоблоком товаров.
- Свойство товаров `OFFERS` типа **Список**: значения определяют принадлежность к блокам.
- Свойство товаров `USAGE` типа **Список**: значения определяют вкладки.
- Шаблон `slider` для компонента `bitrix:catalog.section` с HTML-разметкой карусели, ожидаемой скриптом (`.hit-carousel`, `.swiper`, `.hit-carousel-prev`, `.hit-carousel-next`).
- Подключённые Swiper и jQuery; в проекте также используется `BX.ready`.

**Важно:** числовые ID инфоблока и значений списков отличаются между сайтами и инфоблоками. Их нужно сверять в административной панели.

## Установка

1. Скопировать `local/include/config.php`, `local/include/section.php` и `local/include/offers-carousel.js` в `/local/include/` сайта.
2. Скопировать `ajax/hit-carousel.php` в `/ajax/hit-carousel.php` сайта. Этот путь используется в `offers-carousel.js`.
3. Убедиться, что на сайте доступны шаблон компонента `slider`, Swiper, jQuery и необходимые CSS-стили.
4. Настроить `config.php` для каталога сайта.
5. Подключить JavaScript **один раз** на странице и разместить вызовы `section.php` в нужных местах.
6. Очистить кеш при необходимости и проверить работу вкладок, AJAX и стрелок.

## Настройка `config.php`

```php
<?php
return [
    'iblock_id' => 16,
    'properties' => [
        'offers' => 'OFFERS',
        'usage' => 'USAGE',
    ],
    'sections' => [
        'hits' => ['title' => 'Хиты продаж', 'offers_id' => 9],
        'news' => ['title' => 'Новинки', 'offers_id' => 10],
        'best' => ['title' => 'Лучшие предложения', 'offers_id' => 11],
    ],
    'tabs' => [
        'all' => ['title' => 'Все товары', 'usage_id' => null],
        'tab1' => ['title' => 'Если нельзя пронести телефон', 'usage_id' => 175],
        'tab2' => ['title' => 'Если стоят глушилки', 'usage_id' => 176],
        // Остальные вкладки добавляются аналогично.
    ],
];
```

- `iblock_id` — ID каталога товаров.
- `properties.offers`, `properties.usage` — символьные коды свойств.
- `sections` — **ручной** список блоков: ключ используется как `$sectionCode`, `title` — заголовок, `offers_id` — числовой ID значения `OFFERS`.
- `tabs` — **ручной** список вкладок: ключ передаётся в AJAX, `title` — текст кнопки, `usage_id` — числовой ID значения `USAGE`; `null` означает отсутствие фильтра по `USAGE`.

В актуальном файле репозитория перечислены все вкладки `tab1`–`tab6`; пример выше сокращён для наглядности.

## Подключение на странице

```php
<?php
\Bitrix\Main\Page\Asset::getInstance()->addJs('/local/include/offers-carousel.js');
?>

<?php
$sectionCode = 'hits';
include $_SERVER['DOCUMENT_ROOT'] . '/local/include/section.php';
?>

<!-- Здесь могут быть другие блоки главной страницы -->

<?php
$sectionCode = 'news';
include $_SERVER['DOCUMENT_ROOT'] . '/local/include/section.php';
?>

<!-- Здесь могут быть другие блоки главной страницы -->

<?php
$sectionCode = 'best';
include $_SERVER['DOCUMENT_ROOT'] . '/local/include/section.php';
?>
```

Код размещается внутри страницы Битрикса после подключения пролога и до футера. Каждый блок подключается отдельно, поэтому между ними можно размещать другой контент. Для нового блока добавьте запись в `sections` и подключите `section.php` с соответствующим `$sectionCode`.

## Как работает решение

1. `section.php` загружает `config.php`, находит настройки по `$sectionCode` и проверяет наличие товаров для текущего `OFFERS`.
2. Для каждой вкладки проверяется наличие товаров с нужным `USAGE`; пустые вкладки не выводятся.
3. При первоначальной загрузке `bitrix:catalog.section` с шаблоном `slider` выводит все товары текущего блока.
4. При клике на вкладку `offers-carousel.js` отправляет `POST` на `/ajax/hit-carousel.php` с параметрами `tab` и `offers`.
5. AJAX-обработчик строит фильтр, возвращает HTML компонента; скрипт заменяет содержимое карусели и инициализирует Swiper заново.

## Проверка после установки

- Все нужные блоки отображаются в заданных местах.
- Блок без товаров не выводится.
- Пустые вкладки скрываются; вкладка «Все товары» показывает товары текущего блока.
- При переключении вкладок товары действительно меняются, страница не перезагружается.
- Стрелки управляют только своей каруселью; адаптивность работает.
- В DevTools → Network запрос `/ajax/hit-carousel.php` возвращает корректный HTML без ошибок PHP.

## Ограничения текущей версии

- `sections` и `tabs` **не формируются автоматически** из значений списков Битрикса; они прописаны в `config.php`.
- Настройки рассчитаны на один каталог. Многосайтовая конфигурация и мультиязычность пока не реализованы.
- В текущем AJAX-файле фильтр по `OFFERS` записан как `'=PROPERTY_OFFERS'`, поэтому при переименовании свойства одного изменения `config.php` недостаточно.
- В текущем AJAX-файле параметр `offers` приводится к числу, но ещё не проверяется по разрешённым `offers_id` из конфигурации. Перед использованием на публичных сайтах стоит добавить эту проверку.
- Параметры `bitrix:catalog.section` пока повторяются в `section.php` и AJAX-обработчике. При изменении настроек компонента нужно учитывать оба файла.
- Внешний вид зависит от шаблона `slider` и CSS сайта.

## Возможные улучшения (не входят в текущую версию)

- Автоматически получать блоки из значений `OFFERS`, а вкладки — из `USAGE`.
- Использовать `XML_ID` значений `OFFERS` вместо числовых ID.
- Добавить конфигурации для разных сайтов и каталогов.
- Вынести общие параметры `catalog.section` в одно место.
