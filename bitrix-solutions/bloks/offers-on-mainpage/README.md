#Описание 
Создаем на главной странице блоки с товарами: Хиты продаж, Новинки, Рекомендуем и др.
В каждом блоке выводятся товары с соответствующими свойствами.
В каждом блоке есть несколько табов в соответствии с областью применения товаров. Первый таб - Все. В нем выводятся все товары. Переключение между табами должно быть без перезагрузки страницы.
Внутри табов товары выводятся каруселью.
#Как создать
##Создаем свойство каталога Применение (USAGE)типа "список". Значения:
у меня использованы
Для автоматизации
Сборка щита
Для удобного монтажа
Для дома
Освещение
Для каждого сайта набор значений этого свойства будет свой.
##Создаем свойство каталога Наши предложения (OFFERS)типа "список". Значения: 
Новинка
Хит продаж
Рекомендуем
Распродажа
другие по необходимости

##На главной странице создаем блоки в соответствии с значениями свойства Наши предложения
Новинка
Хит продаж
Рекомендуем
Распродажа
Структура блока представлена в файле section.php
##В каждом блоке делаем табы в соответствии с значениями свойства Пременение
##В табах размещаем компонент bitrix:catalog.section с фильтром, выводящим элементы с значением свойства Наши предложения, соответсвующим этому блоку с шаблоном "slider"
##Создаем один общий скрипт, регулирующий переключение табов. Скрипт в файле script.php
