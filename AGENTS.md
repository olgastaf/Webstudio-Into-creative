# AGENTS.md

## Project overview
This repository contains reusable Bitrix solutions: menus, sliders, forms, headers, and other layout snippets.

## Repository structure
- `templates/` — ready-to-use solution templates.
- `snippets/` — reusable code fragments.
- `prompts/` — task scenarios for the AI agent.
- `assets/` — screenshots and preview images.
- `docs/` — conventions and additional notes.

## Working rules
- Prefer minimal changes to existing templates.
- Keep file names short, descriptive, and in English.
- Do not overwrite user-specific project settings.
- Add or update README files when adding a new solution.

## When creating a new solution
1. Choose the correct category folder.
2. Copy the base template.
3. Adapt only the necessary files.
4. Save a screenshot if the solution has visual output.
5. Update the relevant README and prompt file.

## Do not
- Do not commit secrets or private keys.
- Do not move files unless structure needs cleanup.
- Do not change working examples without a reason.
