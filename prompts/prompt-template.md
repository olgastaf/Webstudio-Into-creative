# Prompt Title

## Goal
Describe what the AI agent should build or modify.

## Context
Explain the repository, template, or feature the agent should use.

## Task
List the exact actions the agent should perform.

## Input
Describe the files, settings, or example data the agent will work with.

## Requirements
- Keep the code clean and reusable.
- Follow the repository structure.
- Do not change unrelated files.
- Keep the solution compatible with Bitrix.
- Preserve existing functionality.

## Output
Describe what the final result should include:
- files created or updated;
- expected behavior;
- any required notes or documentation.

## Notes
Add any important limitations, styling rules, or implementation details.
