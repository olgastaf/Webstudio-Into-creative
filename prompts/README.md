# Prompts

This folder contains reusable prompt templates for AI agents.

## Purpose

Each file in this folder describes one specific workflow or task scenario that an AI agent can follow to generate or modify a solution from this repository.

## How to use

1. Choose the prompt that matches your task.
2. Read the related template or solution folder in the repository.
3. Paste the prompt into your AI agent or editor.
4. Replace placeholders with the current project details.
5. Review the generated result before applying it to a real project.

## Recommended structure

- One prompt file = one workflow.
- Keep prompts short, clear, and task-oriented.
- Use a consistent file naming style.
- Link each prompt to the related template folder when possible.

## Example prompt types

- `menu-dropdown.md`
- `menu-mega.md`
- `slider-basic.md`
- `form-contact.md`

## Writing rules

- Describe the goal first.
- Include only the minimum context needed.
- Mention important file names and folders.
- State what the agent should not change.
- Add output requirements if needed.

## Notes

These prompts are intended for reusable Bitrix solutions and can be adapted for different projects.
