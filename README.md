# Меню из разделов каталога для 1С-Битрикс

Набор файлов для реализации меню, автоматически формируемого из разделов каталога (или другого инфоблока) в шаблоне сайта на 1С-Битрикс.

## Что входит в комплект

- Обычное меню.
- Расширенное меню.
- Скрипт вставки меню в шаблон сайта.

## Назначение

Решение используется для отображения меню, автоматически формируемого из разделов каталога в шапке или другом блоке шаблона.  
Подходит для интернет-магазинов и корпоративных сайтов на 1С-Битрикс.

## Структура файлов

- `.bottom.menu.php` — файл обычного меню.
- `bottom.menu_ext.php` — файл расширенного меню.
- `include_menu.php` — скрипт подключения меню в шаблон.

## Как использовать

1. Скопировать файлы корневую папку сайта или в папку раздела, в котором требуется вывести это меню.
2. Подключить скрипт вставки меню в шаблоне сайта.
3. Проверить корректность путей и отображение пунктов меню.
4. При необходимости изменить шаблон меню и адаптировать стили и логику вывода под дизайн проекта.

## Примечание

Логика построена под задачи работы с разделами каталога и может быть доработана под конкретную структуру сайта.
